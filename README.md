# 노을 포격전

포트리스 / Scorched Earth 스타일의 턴제 포격 게임. 최대 10대(사람·CPU 섞어서)가 한 전장에서 차례로 쏘는 난타전.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 로컬 서버로 띄운다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 게임 흐름

설정(인원 2~10, 각자 조종·탱크 선택) → 상점(사람 플레이어 차례대로, CPU는 자동) → 전투 → 라운드 순위·골드 정산 → 상점 → … → 정한 라운드 수(1/3/5)가 끝나면 최종 순위

- 전장은 화면보다 넓고(1800px) 카메라가 현재 탱크와 포탄을 따라간다. 끌거나 미니맵·참가자 이름을 눌러 둘러볼 수 있다.
- 마지막까지 살아남은 탱크가 라운드 승리. 최종 순위는 승리 수, 동률이면 누적 피해.
- 탱크마다 **기본 무장**(무제한)과 **특기**(쓰면 몇 턴 대기)가 있다.
- 상점의 무기는 **어느 탱크든** 살 수 있다(소모품, 라운드를 넘어 유지).
- **강화**는 플레이어 단위로 무기별 Lv0~3. 그 무기와 그 무기가 들어간 조합 무기에 모두 적용된다.
- **조합**: 조합대에서 두 기본 무기를 골라 조합법을 등록(100G)하면 조합 무기를 살 수 있다.
- 아이템(수리, 방어막, 연료)은 자기 턴에 하나만, 턴 소모 없이 쓴다.
- 시작 자금 400G. 보상: 참가 100 + 준 피해 × 2 + 격파 × 100 + 순위 보너스 150/90/50 (`src/config.js`의 `ECON`).

## 조합 규칙 (`src/data/weapons.js`의 `merge`)

무기는 부품의 묶음이다: 여러 발(`count`), 탄도 보정(`windK/gravK/speedK`), 분열(`bomblets`), 튕김(`bounces`), 굴착(`drill`), 흙(`dirt`).

- 폭발력(피해 × 반경)이 큰 쪽이 **주 탄두**, 다른 쪽은 **부품**을 보탠다. 이름은 `보조의 prefix + 주 탄두 이름` (예: 집속탄 + 굴착탄 → 집속 굴착탄).
- 피해 = 주 탄두 + 보조 × 25%, 반경 = 주 탄두 + 보조 × 15%.
- 부품은 합쳐진다(같은 부품은 큰 값). 자탄은 나머지 부품을 물려받으므로 집속 굴착탄의 자탄은 각각 땅을 뚫는다.
- 큰 탄두를 여러 발이나 자탄으로 늘리면 한 발당 피해 ×0.55, 반경 ×0.7.
- 가격은 두 재료 가격 합의 85%, 발 수는 적은 쪽.

## 구조

| 파일 | 역할 |
|---|---|
| `src/data/weapons.js` | 무기 목록, 강화 단계별 성능 `weaponStats`, 강화 비용 |
| `src/data/tanks.js` | 탱크 종류(체력, 기동, 장갑, 기본 무장/특기) |
| `src/data/items.js` | 아이템 |
| `src/battle.js` | 한 라운드의 난타전: 턴 순서, 카메라, 이동, 탄도, 폭발, 피해 |
| `src/terrain.js` | 파괴 가능한 지형(픽셀 마스크 + 캔버스), 배경 |
| `src/ai.js` | CPU 표적 선택·조준(탄도 시뮬레이션)과 CPU 상점(조합 포함) |
| `src/render.js` | 전장 그리기, 미니맵, 탱크 실루엣 |
| `src/main.js` | 화면 전환, 설정·상점·조합대 UI, HUD, 입력 |

## 무기 추가하기

`WEAPONS`에 항목을 넣으면 상점, 조합대, 전투, CPU에 모두 나타난다. 동작은 부품 필드로 정하고, 조합할 때 붙을 `prefix`도 정해 준다.
새로운 부품이 필요하면 `battle.js`의 `stepProj`/`blast`에 처리를 넣고, `merge`에 합치는 규칙을 추가한다.
