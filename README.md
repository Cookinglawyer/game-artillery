# 날벼락전쟁

포트리스 / Scorched Earth 스타일의 캐주얼 턴제 포격 게임. 최대 10대(사람·CPU 섞어서)가 한 전장에서 차례로 쏘는 난타전.

## 실행

ES 모듈을 쓰므로 파일을 직접 열지 말고 로컬 서버로 띄운다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 휴대폰 앱으로 설치 (PWA)

GitHub Pages 등 https 주소로 올리면 설치형 웹앱으로 동작한다.

- 안드로이드 크롬: 화면 위 **앱 설치** 버튼, 또는 브라우저 메뉴 → **앱 설치 / 홈 화면에 추가**
- 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**
- 한 번 연 뒤에는 인터넷 없이도 실행된다(`sw.js`). 온라인일 때는 항상 최신 파일을 먼저 받는다.
- 새 파일을 추가하면 `sw.js`의 `SHELL` 목록에 넣고 `CACHE` 버전을 올린다.
- 아이콘은 `icons/`, 앱 이름·색은 `manifest.webmanifest`.

### GitHub Pages 켜기

저장소 **Settings → Pages → Source: Deploy from a branch, Branch: main, / (root) → Save**.
1~2분 뒤 `https://cookinglawyer.github.io/game-artillery/` 에서 열린다. `main`에 올릴 때마다 자동 갱신.

## 조작

- **조준:** 내 탱크(또는 화살표 끝)를 잡고 끈다. 화살표 방향이 각도, 길이가 파워. 점선 반원이 최대 파워.
- **미세 조정:** 아래 조작판의 ↶ ↷(각도) − +(파워) 버튼, 숫자 직접 입력, 키보드 방향키(Shift와 함께 0.1씩).
- **둘러보기:** 빈 곳을 끌거나 왼쪽 위 미니맵을 누른다.
- 전투 화면은 화면 전체를 쓰고, 세로 화면에서는 위쪽을 하늘로 채워 높은 포물선도 보인다(`render.js`의 `viewFor`).

## 게임 흐름

설정(인원 2~10, 각자 조종·나라 선택) → 상점(사람 플레이어 차례대로, 컴퓨터는 자동) → 전투 → 라운드 순위·골드 정산 → 상점 → … → 정한 라운드 수(1/3/5)가 끝나면 최종 순위

- 나라 8개(한국 K2·미국 에이브럼스·북한 천마-20·러시아 T-14·중국 99A식·일본 10식·독일 레오파르트 2A7·프랑스 르클레르). 각 나라 지도자가 포탑 위에 타고 있다. **성능은 모두 같고 생김새만 다르다**(`src/data/tanks.js`, 지도자 바뀌면 `leader`·`rider`만 수정).
- 마지막까지 살아남은 탱크가 라운드 승리. 최종 순위는 승리 수, 동률이면 누적 피해.
- 모두 **기본탄**을 무제한으로 가진다. 나머지 무기는 상점에서 싸게 산다(소모품, 라운드를 넘어 유지).
- **강화**는 플레이어 단위로 무기별 Lv0~3. 그 무기와 그 무기가 들어간 조합 무기에 모두 적용된다.
- **조합**: 조합대에서 두 무기를 골라 조합법을 등록(30G)하면 조합 무기를 살 수 있다.
- **방어막**: 상점에서 1~3단계(30/60/100, 15/35/60G)를 사 두면 다음 라운드 시작 때 탱크 둘레에 원으로 생겨 체력보다 먼저 피해를 막는다. 단계가 높을수록 두껍다.
- 아이템(수리, 연료)은 자기 턴에 하나만, 턴 소모 없이 쓴다.
- 시작 자금 300G. 보상: 참가 80 + 준 피해 × 1 + 격파 × 40 + 순위 보너스 80/50/30 (`src/config.js`의 `ECON`).

## 무기 (`src/data/weapons.js`)

기본탄(반경 50, 무제한), 3분할탄, 5분할탄, 유도탄, 자폭 드론, 벙커버스터(세 번 폭발), 베이비 누크(반경 96), 누크(반경 160), 직사 레이저, 바나나 폭탄, 수박 폭탄, 통통볼, 두더지탄, 폭죽탄, 펀치 글러브(날려버림), 순간이동탄, 회복 꽃다발(적도 회복), 흙더미탄.

## 조합 규칙 (`merge`)

무기는 부품의 묶음이다: 갈라짐(`bomblets`, `radial`), 떨어진 자리 조각(`burst`), 추적(`homing`, `drone`), 재발사(`hops`), 튕김(`bounces`), 굴착(`drill`), 탄도 보정(`windK/gravK/speedK`), 밀어내기(`knock`), 회복(`heal`), 순간이동(`teleport`), 흙(`dirt`).

- 폭발력이 큰 쪽이 **주 탄두**, 다른 쪽은 **부품**을 보탠다. 이름은 `보조의 prefix + 주 탄두 이름` (예: 드론 + 누크 → 드론 누크).
- 피해 = 주 탄두 + 보조 × 25%, 반경 = 주 탄두 + 보조 × 15%. 부품은 합쳐진다(같은 부품은 큰 값).
- 큰 탄두를 여러 갈래·조각으로 늘리면 한 발당 피해 ×0.55, 반경 ×0.7.

## 구조

| 파일 | 역할 |
|---|---|
| `src/data/weapons.js` | 무기 목록, 강화 단계별 성능 `weaponStats`, 강화 비용 |
| `src/data/tanks.js` | 나라별 탱크 모양·위장색·국기와 지도자 그림 정보(성능은 공통 `TANK_STATS`) |
| `src/data/items.js` | 아이템, 방어막 단계(`SHIELDS`) |
| `src/battle.js` | 한 라운드의 난타전: 턴 순서, 카메라, 이동, 탄도, 폭발, 피해 |
| `src/terrain.js` | 파괴 가능한 지형(픽셀 마스크 + 캔버스), 배경 |
| `src/ai.js` | CPU 표적 선택·조준(탄도 시뮬레이션)과 CPU 상점(조합 포함) |
| `src/render.js` | 화면 비율별 시야(`viewFor`), 하늘·구름, 탱크와 지도자(`drawVehicle`), 무기별 탄 모양, 조준 화살표, 폭발, 미니맵 |
| `src/main.js` | 화면 전환, 설정·상점·조합대 UI, HUD, 입력, PWA 등록 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 오프라인 실행, 설치 정보, 앱 아이콘 |

## 무기 추가하기

`WEAPONS`에 항목을 넣으면 상점, 조합대, 전투, CPU에 모두 나타난다. 동작은 부품 필드로 정하고, 조합할 때 붙을 `prefix`도 정해 준다.
새로운 부품이 필요하면 `battle.js`의 `stepProj`/`blast`에 처리를 넣고, `merge`에 합치는 규칙을 추가한다.
